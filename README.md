## Descripción

Este repositorio contiene la implementación en Python de los ejercicios propuestos en la **Guía 1 de ECDI 2026**. 
El objetivo es resolver ecuaciones diferenciales, visualizar campos de pendientes, soluciones particulares y 
analizar ecuaciones autónomas utilizando herramientas computacionales.

## Estructura del Proyecto

La carpeta del proyecto contiene los siguientes archivos:

- **`ejercicio_1.py`**: Script para resolver ejercicios de campos de pendientes y soluciones particulares (PVI).
- **`ejercicio_2.py`**: Script para el análisis de puntos críticos y diagramas de fase de ecuaciones autónomas.
- **`ejercicio_3_y_4.py`**: Script para modelar problemas de población (crecimiento y análisis de estabilidad).
- **`Guia_1_ECDL_2026.pdf`**: Documento original con los enunciados de los ejercicios.
- **`Resultados.pdf`**: Documento con los resultados explicados.

## Configuración del Entorno

Para ejecutar los scripts es necesario tener instalado Python 3.8 o superior y las siguientes librerías:

### Dependencias

- `numpy`
- `scipy`
- `matplotlib`
- `sympy`
